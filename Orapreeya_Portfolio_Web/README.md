# Orapreeya Portfolio

เว็บ Portfolio แบบ Static HTML/CSS สำหรับ GitHub Pages

## เปิดในเครื่อง
ดับเบิลคลิก `index.html`

## Deploy ด้วย GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลด `index.html` และโฟลเดอร์ `assets`
3. ไปที่ Settings → Pages
4. Source: Deploy from a branch
5. Branch: main / root
6. กด Save แล้วรอระบบสร้างลิงก์เว็บไซต์

ไฟล์ PDF ใน `assets` เป็นเอกสารโครงงานที่มาจากไฟล์ต้นฉบับที่ใช้สร้าง Portfolio
